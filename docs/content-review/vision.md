# 시력교정 클리닉 원고 검토 요청서

- 대상 메뉴: 수술 전 진료 시스템 / LASIK·LASEK / Smile 4 me / 수술 후의 관리 시스템 / FACT CHECK
- 원고 출처: 기존 푸른안과 홈페이지(VB1000·VB2000·VB3000·VB5000·VB6000)
- 원칙: 사실(검사 수, 장비명, 수술 과정, 주의사항 기간)은 유지하고, 의료광고 심의 기준에 걸릴 수 있는 최상급·비교·보장성·경력 연수 표현은 중립적으로 바꿨습니다.
- 모든 이미지는 임시 자리(플레이스홀더)이며, 장비 사진은 VisuMax 실사진만 사용했습니다.

## 1. 수술 전 진료 시스템 (/vision/pre-care)

**(a) 가져온 내용**
- 소개: 수술 전 검사가 가장 중요, 오랜 경험 기반의 정밀 특수검사
- 검사 원칙 3가지(필요한 검사를 빠짐없이 / 검사의 질 / 의료진의 신중한 판단)를 카드로 정리
- 33가지 수술 전 검사: 원문 33개 항목을 4개 분류(시력·굴절 8 / 각막 6 / 안구 구조·기능 7 / 망막·시신경 12)로 묶어 표시
- “알고 계신가요? 수술 전 망막검사는 필수” + 망막클리닉 보임 바로가기
- 원문 하단의 커스텀 Q / Xtra / Visu 라식 소개는 LASIK·LASEK 페이지와 중복이라 그쪽에만 실었습니다.

**(b) 수정한 표현**

| 원문 | 변경 | 이유 |
|---|---|---|
| 안전한 수술, 최고의 결과를 위해서 | 시력교정수술에서 가장 중요한 단계는 수술 전 검사입니다 | 최상급 표현(최고) |
| 타안과와 차별되는 특수 진단검사장비들을 이용 | 삭제 (정밀 장비 표현만 유지) | 다른 병원과 비교 |
| 환자마다 눈에 맞는 최선의 수술을 선택함은 기본 | 검사 결과를 종합해 눈에 맞는 수술 방법을 함께 정합니다 | 최상급 표현 |
| 10번 그 이상이라도 반복하여 | 필요한 만큼 반복 검사해 | 과장으로 보일 수 있는 수치 |
| 33단계의 수술 전 검사 | 33가지 수술 전 검사 | 순서가 아닌 검사 항목이므로 |
| 막전위도검사(ERG.) | 망막전위도검사(ERG) | 오타 |

**(c) 병원 확인 필요**
- **33가지 검사를 현재도 모두 시행하는지**, 분류가 맞는지
- 현재 보유 장비 확인: Orbscan, Zywave, Oculyzer, Scheimpflug(Pentacam 등), Pupilometer, Optos, Humphrey, VEP·ERG 장비
- “안축장길이검사(SCAN검사)”: A-Scan인지, IOLMaster 등 다른 장비인지
- “DNA 유전자검사”: 각막이영양증(아벨리노) 유전자검사인지 — 맞다면 명칭을 구체적으로 표기할지
- “망막검영기 검사”와 “타각식 굴절검사(RETINOSCOPE)”가 중복인지
- 망막클리닉 보임 사진

## 2. LASIK / LASEK (/vision/lasik)

**(a) 가져온 내용**
- 도입: Technology for human life (기술 발전과 시력교정수술)
- 라식 정의·회복(3~4시간 이물감, 다음 날 일상 복귀) + 특징 5가지
- 라섹 정의·회복(3~4일 통증) + 특징 5가지
- 프리미엄 옵션: 커스텀 Q Visu 라식/라섹, 라식·라섹·스마일 Xtra(Light Link + 리보플라빈), Visu 라식(VisuMax + EX500)
- 라식·라섹 수술 후 증상 Q&A 2개

**(b) 수정한 표현**

| 원문 | 변경 | 이유 |
|---|---|---|
| 수술 다음날 시력이 가장 탁월합니다 | 대개 다음 날부터 일상생활이 가능합니다 | 결과 보장성 표현 |
| 안경 최대 교정시력 이상의 나안 시력을 목표로 합니다 | 삭제 | 결과 보장으로 오인 가능 |
| 세계최고 펨토세컨레이저 비쥬맥스 + 안과의사들 사이에 가장 인정받고 있는 EX500 | 펨토초 레이저 VisuMax + 엑시머 레이저 EX500 | 최상급(세계최고, 가장) |
| 24년간 수술 노하우 / 20년 이상의 무통라섹 노하우 / 25년 동안의 노하우 | 2001년 개원 이후 이어온 경험 / 오랜 라섹 수술 경험 | 해가 바뀌면 틀려지는 연수 표기, 페이지마다 숫자 불일치 |
| 각막확장증 발병률 0%에 수렴하는 안전성 | 각막확장증 예방을 우선하는 수술 기준 | 객관적 근거 없는 수치·안전성 보장 |
| 고난이도 시력교정 수술의 풍부한 경험 | 고도 근시·난시 등 다양한 시력교정 경험 | 표현 완화 |
| 평생토록 건강한 눈을 위한 관리 시스템 | 수술 후에도 이어지는 장기적인 관리 | 보장성 표현 완화 |
| 일상에 바로 복귀할 수 있는 시스템 (라섹) | 회복 부담을 줄이도록 합니다 | 라섹 3~4일 통증 설명과 모순 |
| 아프지 않은 라섹 / 무통라섹 | 통증을 줄이기 위한 노하우 | 무통 보장 표현 |
| Alcon사의 최신버전, 최신 스펙 EX500 | Alcon사 EX500 | ‘최신’은 시간이 지나면 사실과 달라짐 |
| 최고의 성적을 자랑했던 레이저 | 삭제 | 최상급 |
| 이러한 후유증을 예방합니다 | 후유증 위험을 줄이는 데 도움이 됩니다 | 효과 보장 표현 |
| 가장 진화된 수술시스템 | 삭제 (각막 보강 시술로 설명) | 최상급 |
| 가장 안전하고 안정적인 비쥬맥스가 가장 낮은 에너지로 안압상승이 거의 없이 | VisuMax가 낮은 에너지로 안압 상승 부담을 줄이며 | 최상급 |
| 안과의사들 사이에 가장 인기가 높은 알레그레토 EX500 | 엑시머 레이저 Allegretto EX500 | 최상급 |
| 높은 디옵터의 눈에서도 정확한 시력교정이 가능 | 고도근시도 정밀하게 교정합니다 | 표현 정리 |

**(c) 병원 확인 필요**
- **EX500(Allegretto) 현재 운용 여부** — 장비 사진이 장비 목록(lib/equipment)에 없어 이미지 미사용. 사진 제공 시 추가 가능
- **Light Link(각막 교차결합) 장비 보유 여부**, Xtra를 스마일에도 시행하는지
- 커스텀 Q / Visu / Xtra 등 상품명 현재도 사용하는지, 가격·패키지 구성 변경 여부
- 각막확장증 관련 수치(“0%에 가까움”)를 쓰려면 근거 자료 필요 — 없으면 현 문구 유지 권장
- 라식 수술 과정, 라섹 수술 과정 일러스트

## 3. Smile 4 me (/vision/smile)

**(a) 가져온 내용**
- 소개: 개원 이후 경험 + 스마일 수술, 레이저 소리·냄새 없음, 집도의와 대화하며 수술
- 수술 과정 3단계(렌티큘 디자인 → VisuMax 커팅 → 작은 절개로 분리)
- 4가지 특징: Low Energy / Small Incision / Safe / Maintenance
- 정밀 교정: VisuMax 장비 실사진, 센트레이션, 난시 맞춤 절개, 500kHz 레이저
- 수술 후 증상 Q&A

**(b) 수정한 표현**

| 원문 | 변경 | 이유 |
|---|---|---|
| 라식/라섹의 한계를 뛰어넘는 차세대 시력교정수술 | 각막 절편 없이 작은 절개로 진행하는 시력교정수술 | 타 수술 대비 우월성 |
| 시력교정수술의 명가 | 삭제 | 과장 |
| 에러율 0%에 도전하는 | 삭제 | 근거 없는 수치 |
| 2017년형 ALL NEW VISUMAX | VisuMax 레이저 | 연식 표기(최신성 오인) |
| 기존 스마일보다 빠른 회복 / 기존 스마일 라식보다 더욱 선명한 시력 | 삭제 | 비교 표현 |
| 부작용을 억제합니다 | 부작용 위험을 줄이는 데 도움이 되며 | 효과 보장 |
| 수술다음날 일상생활로 즉시 돌아갈 수 있습니다 | 대부분 수술 다음 날부터 일상생활이 가능합니다 | 개인차 반영 |
| 장비가 허용하는 가장 작은 절개 | 장비가 허용하는 범위 안에서 적절한 크기로 절개 | FACT CHECK(“작을수록 좋은 것은 아님”)과 논리 일치 |
| 수술 후 통증이 거의 없으며 | 통증과 회복 부담이 적고 | 보장성 표현 |
| 라식이나 라섹보다 안전함 / 더욱 안전하고 회복이 빠릅니다 | 각막 절편 없이 보우만막을 보존하는 방식 (각 수술의 주의점을 중립적으로 설명) | 타 수술 대비 우월성 |
| 스테로이드 안약으로 인한 녹내장의 가능성 | 스테로이드 안약 사용에 따른 안압 상승에 주의 | 표현 정확화 |
| 개원이래 각막확장증 발생율 0%에 가깝습니다. 타 병원에 비하면 현저히 낮은 발생확률 | 삭제 (“안전하지 않으면 수술하지 않는다”는 원칙만 유지) | 근거 없는 수치 + 타 병원 비교 |
| 고도의 차별화된 펨토세컨드 레이저로 500kHz의 빠른 속도를 자랑 | 500kHz 고속 레이저 빔 | 과장 |
| 기존 라식수술보다 약 1000배 정교한 0.005mm 이하 | 삭제 | 근거 불명확한 비교 수치 |
| 기존 레이저 시력교정수술에 비하여 부작용 확률을 낮췄기 때문에 뛰어난 안전성 | 삭제 | 비교·우월성 |

**(c) 병원 확인 필요**
- **현재 VisuMax 모델** (VisuMax 500kHz인지, VisuMax 800 등으로 교체됐는지) — 500kHz 수치가 모델에 따라 달라짐
- “스마일 전용 수술실” 현재도 운영하는지
- Smile4me 명칭 계속 사용 여부
- 라식 절개 / 스마일 절개 비교 일러스트, 수술 과정 이미지

## 4. 수술 후의 관리 시스템 (/vision/post-care)

**(a) 가져온 내용**
- 소개: 수술 후 관리가 평생 눈 건강을 좌우
- 수술 후 주의사항 14개 항목 × 라식/라섹/스마일 비교표 (모바일에서는 항목별 카드)
- 근거리 작업 시 30분마다 휴식 안내
- 더 좋은 시력을 위한 원칙 2가지(망막클리닉 보임 추가 검사, 당일 검사·당일 수술 지양 + 굴절검사 최소 2회)

**(b) 수정한 표현**

| 원문 | 변경 | 이유 |
|---|---|---|
| 스마일 수술은 라식과 라섹 수술과는 달리 수술부위가 매우 안정적이라서 자주 내원할 필요 없음 | 스마일 수술은 절개가 작아 상대적으로 내원 부담이 적지만, 정기 검진 일정에 맞춰 내원 | 비교 표현 완화, 검진 누락 방지 |
| 병원에 자주 올수록 눈은 더욱 건강해집니다 | 안내드린 정기 검진 일정에 맞춰 내원해 주세요 | 과도한 내원 유도로 보일 수 있음 |
| 수술후 재발 | 근시 퇴행 | 용어 정리 |
| (표 상단) | “개인차가 있으니 의료진 안내를 우선해 주세요” 추가 | 일률적 기준으로 오인 방지 |

**(c) 병원 확인 필요**
- **주의사항 기간 전체가 현재 기준과 같은지** (특히 수영장 라식 2개월 / 라섹 1개월, 운전 라섹 5일, 라섹 가벼운 운동 1~2주)
- 보호안대 착용 기간(라식·라섹 4주, 스마일 2주)
- **보임 망막센터 망막 전문의 수** — 원문 “4명”은 인원 변동 가능성이 있어 본문에서는 숫자를 뺐습니다. 넣기를 원하시면 현재 인원 알려 주세요
- 당일 검사·당일 수술 지양, 굴절검사 최소 2회 — 현재 운영 방식과 같은지

## 5. FACT CHECK (/vision/fact-check)

**(a) 가져온 내용**
- 원문 10문 10답을 모두 유지, 질문은 짧게 다듬고 답변 앞에 한 줄 결론(아닙니다 / 받을 수 있습니다 등)을 붙임
- Q01에 수술 결정 전 체크리스트 8개 유지
- Q05에 1mm / 2~4mm 절개 비교 이미지 자리

**(b) 수정한 표현**

| 원문 | 변경 | 이유 |
|---|---|---|
| 라식, 라섹, 스마일라식의 진실! 시원하게 설명해드립니다 | 시력교정수술, 사실은 이렇습니다 | 어조 정리 |
| (체크리스트) 각막지형도 장비를 완벽하게 갖추고 있는가? | 충분히 갖추고 있는가? | 과장 완화 |
| (Q03) 실제 라식 수술을 받은 비율이 일반인보다 오히려 더 높다는 보고가 있습니다 | 안과의사 중에도 시력교정수술을 받은 사람은 적지 않습니다 | 출처 불명 통계 |
| (Q03) 직접 행동으로 보여주기 위해 수술을 받지 않았나 하는 생각이 듭니다 | 삭제 | 추측성 문장 |
