# 백내장 메뉴 원고 검토 요청

기존 홈페이지(E1000~E7000) 원고를 바탕으로 새 홈페이지 문구를 다시 썼습니다.
의료광고 심의 기준(최상급·비교·효과 보장 표현 제한)에 맞춰 일부 표현을 바꿨습니다. 아래 내용을 확인해 주세요.
이미지는 모두 임시 자리(Placeholder)이며, 장비 사진은 기존 홈페이지 사진(LUMERA700, Centurion, Ellex YAG)을 사용했습니다.

## 1. 푸른 백내장 노안센터 (`/cataract/center`)

**(a) 가져온 내용**
- 센터의 강점 세 가지: 풍부한 수술 경험 / 고난이도 수술 경험을 갖춘 의료진 / 수술 장비
- 2001년 개원, 누적 30,000례 이상, 충남·전남 지역 환자 내원
- 정기 학술 컨퍼런스
- 장비: Zeiss LUMERA 700(수술 현미경), Alcon Centurion(초음파 유화 장비) 설명

**(b) 바꾼 표현**
| 원문 | 변경 | 이유 |

| 전북지역에서 … 가장 많이 방문해 주시는 안과 | 삭제 | 객관적 근거가 필요한 비교 표현 |

## 2. 백내장 수술 선택 방법 (`/cataract/choice`)

**(a) 가져온 내용**
- 기본 수술 4단계: 2.2mm 절개 → 전낭 원형절개(CCC) → 초음파 유화술로 수정체 제거 → 인공수정체 삽입
- 수술 개념의 변화(일반 → 굴절 백내장 수술)
- 일반 vs 다초점 선택 기준(생활 습관·비용·눈 질환), 다초점 신중 대상(망막 질환·녹내장·불규칙 난시), 고도근시 시 근시를 일부 남기는 방법

**(b) 바꾼 표현**
| 원문 | 변경 | 이유 |
|---|---|---|
| 돋보기가 필요치 않게 된 것 / 안경 도움 없이 생활이 가능 | 안경·돋보기 의존을 줄이고 싶은 분 / 원거리와 근거리를 함께 보도록 돕습니다 | 효과 보장 표현 |
| 경제적으로 부담이 덜하고 … / 경제적으로 부담이 되고 … | 비용 부담을 줄이고 싶은 분 | 비용 언급을 중립적으로 |
| (센츄리온이나 인피니티 장비) | 삭제 | 장비 보유 확인 필요 |

**(c) 확인 필요**
- 절개창 크기 2.2mm 현재도 동일한지
- Infiniti 장비 현재 보유 여부(원문에 언급됨, 현재 장비 목록에는 없음)
- 수술 단계 그림 4장 새로 제작 필요

## 3. 프리미엄 백내장 수술 (`/cataract/premium`)

**(a) 가져온 내용**
- 정의(다초점·굴절 백내장 수술), 수술법은 일반과 같고 렌즈만 다름
- 다초점 렌즈의 한계(빛 번짐, 대비감도 저하)
- 권하지 않는 경우: 야간 운전 직업, 정밀 작업, 예민한 성격, 불규칙 각막난시·진행된 녹내장·황반 질환
- 인공수정체 종류별 비교표, 클라레온 설명

**(b) 바꾼 표현**
| 원문 | 변경 | 이유 |
|---|---|---|
| 90%의 환자분에서 만족스러운 원거리 시력, 80~90%에서 돋보기 없이 근거리 작업 | 많은 경우 안경 없이 먼 곳을 보고 돋보기 없이 독서·컴퓨터 작업을 할 수 있게 됩니다 + "개인차" 각주 | 치료 효과 수치 제시(출처 불명확) |
| 양안 레스토어 렌즈 설문조사 결과 90% 만족 | 삭제 | 특정 제품 만족도 인용, 현재 표에 없는 렌즈 |
| 안경으로부터 자유로워진다 | 굴절이상과 노안까지 함께 개선 | 효과 보장 표현 |
| 성격이 예민하신 분 | 시각 변화에 예민한 분 | 표현 순화 |
| 클라레온 = 알콘의 최신 인공수정체 플랫폼 | 알콘의 인공수정체 플랫폼 | '최신' 표현의 시의성 |

- 비교표는 10개 렌즈 열을 4개 유형(일반·토릭·삼중초점·초점심도 확장)으로 묶어 정리했습니다. 각 다초점 렌즈의 토릭 모델은 "토릭 모델 있음"으로 표기했습니다.

**(c) 확인 필요**
- **비교표의 토릭(단초점 난시교정) 렌즈 값**: 원문에 근거리 "비교적 선명", 야간 빛 번짐 "간혹 있음"으로 되어 있어 일반 단초점 렌즈와 다릅니다. 원문 오류가 의심되니 확인 부탁드립니다(통상 단초점 토릭은 근거리 흐림, 빛 번짐 거의 없음).
- 현재 사용 중인 렌즈 목록(파인비젼, 팬옵틱스, 팬옵틱스 클라레온, 비비티 및 각 토릭) — 추가·단종 렌즈
- 렌즈 제품명(상표) 노출 여부: 의료광고 심의에서 문제 될 수 있어 유형명만 표기하는 방안도 가능
- 가격은 표기하지 않았습니다.

## 4. 고난이도 백내장 수술 (`/cataract/advanced`)

**(a) 가져온 내용**
- 초음파 유화 장비 발전, 그럼에도 어려운 경우(산동 불량·좁은 전방·지지 조직 손상)
- 합병증·2차 수술 가능성, 섬유소대 해리 백내장에 대한 공막고정술
- 말기 백내장(센터 페이지 원고에서 가져옴)

**(b) 바꾼 표현**
| 원문 | 변경 | 이유 |
|---|---|---|
| 아무리 백내장이 딱딱하더라도 … 손상을 거의 입히지 않으면서 | 단단한 백내장도 … 손상을 줄이며 | 단정적 표현 |
| 환자의 만족도를 높이고자 최선을 다하고 있습니다 | 눈 상태에 맞는 방법으로 시행합니다 | 간결화 |
| 위 그림 3번째 / 아래 그림 참조 | 삭제(유형 카드·이미지로 대체) | 새 레이아웃 반영 |

**(c) 확인 필요**
- 시행 중인 공막고정술 방법(예: 봉합 고정, 무봉합 공막 내 고정 등)을 구체적으로 적을지
- 유형 이미지 4장, 공막고정술 그림 2장 새로 제작 필요(기존 그림 재사용 가능 여부)

## 5. 레이저 백내장 수술 (`/cataract/laser`)

- 일반 vs 레이저 비교 이미지·표
- 세 가지 특징: 정확한 전낭 절개 / 초음파 사용량·수술 시간 감소 / 굴절이상까지 고려한 맞춤 수술

**(b) 바꾼 표현**
| 원문 | 변경 | 이유 |
|---|---|---|
| 보다 정확하고, 안전한 백내장 수술 | 보다 정밀한 방식의 백내장 수술 | '안전' 단정 |
| 더 안전하게! 합병증 확률 최소화, 빠른 회복! | 더 편안하게 — 초음파 사용량과 수술 시간 감소 | 효과 보장 |
| 합병증이 없어 수술 후 빠른 회복을 기대 | 삭제 | 합병증 없음 단정 — 허위·과장 우려 |
| 작은 차이로 시력 오차가 발생할 수 있는 칼날 방식과는 달리 | 삭제(레이저 장점만 설명) | 다른 수술 방식 비하 비교 |
| 굴절 오차 … 최소화하였습니다 | 줄이는 데 도움이 됩니다 | 단정 표현 |
| 백내장+노안교정+근시+난시를 모두 해결 / 더 완벽하고 | 난시 등 굴절이상, 노안 교정까지 맞춰 계획 | 효과 보장·최상급 |
| 높아진 시력의 질 / 선명하고 높은 시력의 질 제공 | 삭제 | 효과 보장 |

**(c) 확인 필요 (중요)**
- **카탈리스(Catalys) 레이저 장비 현재 보유·운영 여부** — 현재 장비 목록(첨단의료장비)에 없습니다. 운영하지 않는다면 메뉴 자체를 숨기거나 문구를 바꿔야 합니다.
- 장비 사진, 3D OCT 이미지, 비교 이미지·표 원본 제공 가능 여부(현재 임시 자리)
- 비교표 내용(원문은 이미지라 텍스트 확인 불가)

## 6. 백내장 수술 후 합병증 (`/cataract/complications`)

**(a) 가져온 내용**
- 합병증 목록 9종
- 안구내염 1,000건당 약 2~4건
- 후낭혼탁: 소아 흔함, 성인 3~5년 후 약 30~50%, YAG 레이저 치료 대상
- 인공수정체 종류에 따른 야간 빛 번짐·달무리

**(b) 바꾼 표현 / 추가한 내용**
- 원문 내용은 거의 그대로 유지하고 카드형으로 정리
- **추가**: "백내장 수술은 안전성이 높은 수술이지만 … 드물게" (도입 문구)
- **추가**: "수술 후 안약 사용과 위생 수칙을 꼭 지켜야 합니다"
- **추가**: "갑자기 눈이 아프거나 충혈이 심해지고 시력이 떨어지면 예약일과 관계없이 바로 내원" (환자 안전 안내)
- YAG 레이저 설명에 기존 장비 사진(Ellex Ultra Q) 사용

**(c) 확인 필요**
- 안구내염 빈도(1,000건당 2~4건), 후낭혼탁 빈도(3~5년 후 30~50%) 수치 유지 여부 — 최근 문헌 기준으로는 더 낮게 보고되기도 합니다
- 추가한 안내 문구 3개의 적절성

## 우선 확인 요청 (요약)
1. 카탈리스 레이저 장비 운영 여부 (레이저 백내장 페이지 존폐)
2. 프리미엄 비교표의 토릭 렌즈 값 오류 여부, 현재 사용 렌즈 목록·제품명 표기 여부
3. 누적 수술 건수 최신화(30,000례+), 집계 기준
4. 삭제한 성과 수치(90%, 80~90%, 설문 90%) 대체 문구 동의 여부
5. Infiniti 장비 보유 여부, 절개창 2.2mm
6. 합병증 빈도 수치 최신성

## /cataract/about — 백내장이란

**(a) 가져온 내용**
- 정의: 수정체가 투명함을 잃고 혼탁해져 빛을 망막까지 제대로 통과시키지 못해 시력 저하를 일으키는 질환
- 원인: 주로 노화, 그 외 자외선 과다 노출·외상·당뇨 (원인 카드 4개로 정리)
- 진행: 보통 서서히 진행 / 초기 — 시력은 크게 떨어지지 않고 침침함·눈부심, 진행 억제 점안제 또는 경과 관찰 / 중기 이후 — 시력 중등도 저하, 방치 시 합병증, 수술 치료 (초기·중기 이후 2단 카드로 정리)
- 기존 임시 문구(Q&A 8개, 장비 소개 4개)는 원고에 근거가 없어 삭제하고, 다른 백내장 페이지(수술 선택 방법·프리미엄·합병증)로 가는 링크 카드로 대체했습니다.

**(b) 바꾼 표현 / 추가한 내용**
| 원문 | 변경 | 이유 |
|---|---|---|
| 백내장 진행을 억제하는 점안제 | 진행을 늦추기 위한 점안제 | 효과 단정 완화 |
| 방치할 경우 여러가지 심각한 합병증이 발생할 수 있기 때문에 | 그대로 두면 여러 합병증이 생길 수 있습니다 | 공포 조장 표현 순화 |
| 수술적인 치료를 하는 것이 좋습니다 | 이 시기에는 수술 치료를 권합니다 | 간결화 |
| 외부의 빛을 망막까지 제대로 통과시키지 못하게 되어 시력 저하를 유발시킵니다 | 바깥의 빛을 망막까지 제대로 통과시키지 못해 시력이 떨어지게 됩니다 | 문장 다듬기(의미 동일) |
