# 원고 검토 요청 — 망막클리닉 보임 · 푸른안과 진료이념

기존 홈페이지 원고를 바탕으로 문장을 다듬고 섹션을 재구성했습니다.
의료광고 심의 기준(최초·유일·최고 등 최상급·비교 표현, 치료 효과 보장, 출처·기준 시점 없는 수치)에 걸릴 수 있는 표현은 순화하거나 삭제했습니다. 근거 자료가 있으면 일부는 다시 넣을 수 있습니다.

## 3. 망막이란 (`/retina/about`)

**(a) 기존 원고에서 가져온 내용**
- 망막 정의(카메라 필름·CCD 비유, 빛을 전기 신호로 바꿔 뇌로 전달)
- 한 번 손상되면 회복이 어려워 조기 진단이 중요하다는 내용
- 대표 질환(당뇨망막병증, 연령관련 황반변성, 망막혈관폐쇄, 망막박리)
- 검사(안저카메라, 형광안저조영, 인도시아닌그린, OCT)

**구성**: 망막이란 → 조기 진단이 중요한 이유 → 안내 띠 → 대표 질환 카드 4개(상세 페이지로 연결) → 정밀 검사 목록 + 장비 페이지 연결

**(b) 수정·순화한 표현**
| 원문 | 변경 | 이유 |
|---|---|---|
| 눈에서 가장 중요한 역할을 하는 조직 | 다른 조직들은 망막이 제 기능을 하도록 돕습니다(최상급 표현 삭제) | 표현을 부드럽게 |
| 영구적으로 실명할 가능성이 높기 때문입니다 | 시력 손실이 영구적으로 남을 수 있으므로 | 불안감을 주는 표현 순화 |

**(c) 병원 확인 필요**
- 대표 질환 4개의 한 줄 설명은 새로 쓴 문장입니다. 망막혈관폐쇄는 상세 페이지가 없어 링크를 넣지 않았습니다.

## 4. 비문증 (`/retina/floaters`)

**(a) 기존 원고에서 가져온 내용**
- 정의(유리체 액화, 혼탁의 그림자), 원인(후유리체박리, 바이스링, 50대 이후)
- 젊은 연령에서는 염증으로 생긴 이차성 비문증인지 감별 필요
- 증상(곤충·점·동그라미·아지랑이·실 모양, 밝은 배경에서 더 뚜렷함)
- 치료: 경과 관찰과 적응, 망막열공이 있으면 방벽 레이저, Nd-YAG 레이저(바이스링이 있을 때), 유리체절제술(제한적)
- 자주 묻는 질문 3개: 원고 내용을 문답으로 재구성

**구성**: 정의 → 원인 → 증상 4종 → 안저검사 안내 띠 → 내원 체크리스트 → 치료 3단계 → 자주 묻는 질문

**(b) 수정·순화한 표현**
| 원문 | 변경 | 이유 |
|---|---|---|
| 비문증을 직접 Nd-YAG 레이져로 타격해서 없애는 치료 | 레이저로 혼탁을 잘게 부수는 치료 | 완전 제거를 보장하는 것처럼 읽힘 |
| (바이스링 동반 시) 효과가 있으며 | 효과를 기대할 수 있으며, 결과에는 개인차가 있습니다 | 효과 보장 표현 순화 |
| 방벽 레이져치료가 반드시 필요 | 방벽 레이저 치료가 필요합니다 | 의미 유지, 어조 정리 |
| 왜나하면, 부분의, 레이져 | 오탈자·표기 정리 | — |

**(c) 병원 확인 필요**
- **새로 추가한 의학 문구**: 내원 체크리스트 중 "갑자기 많아졌다", "빛이 번쩍임", "시야가 커튼처럼 가려짐"은 원고에 없던 내용입니다(일반적인 망막열공·박리 경고 증상). 의학적으로 맞는지 확인해주세요.
- 비문증 레이저 치료를 지금도 하고 계신지 확인 부탁드립니다.
