# 망막·백내장 질환 페이지 검토 요청 (2026-10 개편)

망막클리닉 보임·백내장 메뉴를 질환별 페이지로 다시 구성했습니다. 문구는 새로 작성했으므로 아래 항목의 의학적 정확성과 병원 실정에 맞는지 확인 부탁드립니다.
(이전 `cataract.md`, `retina-diseases.md`의 페이지 중 일부는 이번 개편으로 없어졌습니다.)

## 메뉴
- 망막클리닉 보임: 망막클리닉 보임(소개 + 장비) · 비문증 · 망막박리 · 망막혈관질환 · 포도막염 · 당뇨망막병증 · 황반변성
- 백내장: 백내장 · 인공수정체 탈구

## 모든 질환 페이지 공통 구성
소개 → 정의·유형 → 원인 → 증상 → 진단 단계 → 치료 → (비교표 · 자가진단 · 예방) → (치료 사례) → 신뢰 포인트 → 자주 묻는 질문

## 확인이 필요한 수치·주장
| 위치 | 내용 | 확인할 점 |
|---|---|---|
| 망막 신뢰 포인트 | 2001년부터 망막 진료 / 매년 400례 이상 망막 수술 / 망막 전문 의료진 4인 / 200° 초광각 검사 | 최신 수치 |
| 백내장 신뢰 포인트 | 30,000례 이상 백내장 수술 / 맞춤 인공수정체 / 망막클리닉 협진 / 수술 후 정기 관리 | 최신 수치 |
| 황반변성 비교표 | 건성 약 90%, 습성 약 10% | 병원 기준 표현 |
| 백내장 인공수정체 비교표 | 단초점 · 다초점(연속초점) · 난시교정 렌즈 | 병원에서 실제 사용하는 렌즈 종류 |
| 포도막염 치료 | 스테로이드 → 조절 어려우면 면역억제제 등 | 병원 치료 방침 |
| 치료 사례 (망막박리·당뇨망막병증·황반변성) | 사례 설명 문구 + 수술 전후 사진 자리 | 실제 게재할 사례와 환자 동의 여부. 사례가 없으면 섹션 삭제 |

## 받아야 할 자료
- 각 질환 소개 이미지, 정의 그림(정상/질환 비교), 증상 일러스트, 치료 사진
- 치료 사례 사진 (환자 동의서 포함)
- 암슬러 격자 이미지 (황반변성)
