# 원고 검토 요청 — 망막 질환 4개 페이지

기존 홈페이지 원고(C4000 당뇨망막병증, C5000 황반변성, C6000 망막박리, C7000 중심성 망막증)를 바탕으로 문장을 다듬고 섹션을 재구성했습니다.
의료광고 심의 기준에 걸릴 수 있는 표현은 순화하거나 삭제했습니다. 해당 기준은 최상급·비교 표현, 치료 효과 보장, 출처나 기준 시점이 없는 수치, 전문의약품 상품명입니다. 근거 자료가 있으면 일부 표현은 다시 넣을 수 있습니다.

네 페이지 모두 **"망막 정밀 검사" 박스를 새로 넣었습니다**. 기존 원고에는 없던 내용이며, 보유 장비(`lib/equipment.ts`) 사진을 함께 보여줍니다. 표시가 없는 이미지는 모두 플레이스홀더이므로 사진이 필요합니다.

---

## 1. 당뇨망막병증 (`/retina/diabetic`)

**구성**: 질환 소개(분류별 이미지 슬라이더) → 분류 카드 3개 → 정기검진 안내 띠 → 망막 정밀 검사(Spectralis HRA 사진) → 치료 3가지(유리체 절제술에 Constellation 사진)

**(a) 기존 원고에서 가져온 내용**
- 정의: 당뇨병으로 망막의 말초 혈관이 손상되어 생기는 대표적인 당뇨 합병증
- 위험 요인: 당뇨를 앓은 기간이 길수록, 혈당 조절이 안 될수록 위험이 커짐. 혈당 조절을 잘해도 15~20년 이상 지나면 상당수에서 발생
- 분류: 비증식성(미세동맥류·경성삼출물·망막출혈, 정기 경과 관찰), 증식성(신생혈관, 유리체출혈·견인성 망막박리, 치료하지 않으면 실명 가능), 당뇨황반부종(중등도 시력 저하, 안구 내 주사 치료)
- 치료: 레이저 광응고술, 항체 주사(VEGF 차단, 재출혈 위험 감소, 황반부종 치료), 유리체 절제술(25G 무봉합, 철저한 혈당 조절 필요)

**(b) 수정·순화한 표현**
| 원문 | 변경 | 이유 |
|---|---|---|
| 65세 이하에서 실명의 첫 번째 원인 | 실명을 일으키는 주요 원인 중 하나 | 출처 없는 순위 표현 |
| 안구내 주사치료를 통하여 시력을 개선시킬 수 있습니다 | 안구 내 주사 치료로 시력 회복을 기대할 수 있습니다 | 효과를 단정하는 표현 순화 |
| 망막주변부의 조직을 인위적으로 파괴시켜 | 레이저로 망막 주변부를 응고시켜 | 불안감을 주는 표현 순화 |
| 무봉합, 25G 유리체절제술이 가능해지면서 수술의 결과가 많이 향상된 편입니다만 | 봉합 없이 진행하는 25G 무봉합 방식으로 시행하며 | 결과를 보장하는 것처럼 읽힘 |
| 좀더 좋은 예후로 이어질 수 있습니다 | 좋은 경과를 기대할 수 있습니다 | 어조 정리 |
| 잘보이는 것은 더 좋은 삶의 질을 의미합니다 | 삭제(망막클리닉 보임 페이지에서 사용 중) | 중복 |

**(c) 병원 확인 필요**
- **새로 쓴 문장**
  - 분류 안내 문구: "신생혈관이 생겼는지, 황반까지 침범했는지에 따라 나뉩니다."
  - 안내 띠: "당뇨가 있다면 눈에 불편이 없더라도 정기적으로 안저검사를 받아 망막 상태를 확인하세요."
  - 망막 정밀 검사 박스 전체: 형광안저혈관조영으로 누출·허혈 부위를 확인하고 OCT로 황반부종을 살핀다는 내용
- 유리체 절제술을 현재도 25G 무봉합 방식으로 시행하는지 확인 부탁드립니다. 다른 게이지(예: 27G)도 쓰고 계시면 알려주세요.
- 슬라이더 이미지 3장(비증식성 안저, 증식성 안저, 황반부종 OCT)과 치료 관련 사진이 필요합니다.

## 2. 황반변성 (`/retina/macular`)

**구성**: 질환 소개 → 종류 카드 2개(건성·습성) → 증상 4가지(원형) → 자가 확인법 → 조기 진료 안내 띠 → 망막 정밀 검사(Zeiss OCT 사진) → 치료 2가지

**(a) 기존 원고에서 가져온 내용**
- 정의: 망막 중심에 있는 황반에 변성이 오는 질환. 적절한 시기에 치료하지 않으면 되돌릴 수 없는 시력 손실이 생김
- 종류: 건성(비삼출성. 망막 외층의 변성·위축과 드루젠 침착, 대개 경미함), 습성(삼출성. 맥락막 신생혈관과 혈액·삼출액, 초기에 치료하지 않으면 중심 시력 영구 손실)
- 증상: 건성은 자각 증상이 없는 경우가 많음, 변형시(직선이 물결치듯 굽어 보임), 습성은 중심 시력 저하
- 한쪽 눈에 먼저 생기면 반대쪽 눈 때문에 모를 수 있으므로 한쪽 눈씩 번갈아 가리며 확인
- 치료: 항체 주사(2000년대 초반 도입, 1~2개월 간격 반복), 광역학 레이저 치료(PDT, 주사 치료 효과가 없는 경우)

**(b) 수정·순화한 표현**
| 원문 | 변경 | 이유 |
|---|---|---|
| 65세 이상에서 실명을 일으키는 첫번째 원인 | 노년층 실명의 주요 원인 중 하나 | 출처 없는 순위 표현 |
| 비가역적인 시력손실에 이르게 됩니다 | 되돌릴 수 없는 시력 손실로 이어질 수 있습니다 | 쉬운 말로 바꾸고 단정 표현 순화 |
| (건성) 실명에 다다르게 되며 실명의 10%를 차지 / (습성) 실명상태의 90%를 차지 | 위축이 심해지면 심한 시력 손실로 이어질 수 있습니다 / "심한 시력 손실은 대부분 습성에서 생깁니다" | 출처 없는 통계 수치 |
| 의사에게나 환자에게나 절망적인 질환이었습니다 | 삭제 | 불안감을 주는 표현 |
| 환자의 80-90%에서 시력 유지 및 향상을 기대할 수 있게 되었습니다 | 시력 유지·개선을 기대할 수 있게 되었습니다. 효과에는 개인차가 있습니다. | 출처 없는 효과 수치, 효과 보장 |
| 광감각물질(비쥬다인) | 광감각물질 | 전문의약품 상품명 노출 |
| 주사치료가 효과가 없는 환자 | 주사 치료에 반응이 부족한 경우 | 어조 정리 |
| (기존 플레이스홀더) 예방 수칙 카드(혈압·혈당·금연 등) | 삭제 | 원고에 없는 내용 |

**(c) 병원 확인 필요**
- **새로 쓴 문장**
  - 자가 확인법 4단계: 원고의 "한쪽 눈씩 번갈아 가리며 확인"을 단계로 풀어 썼습니다. 암슬러 격자 이미지를 넣을 예정입니다.
  - 증상 원형 문구 4개(원고 내용을 짧게 줄인 것)
  - 망막 정밀 검사 박스 전체: OCT로 드루젠·망막 아래 액체·신생혈관을 확인하고 주사 간격을 정한다는 내용
- 광역학 치료(PDT)를 현재도 시행하는지 확인 부탁드립니다.
- 실명 비율(10%·90%)이나 효과 수치(80~90%)를 다시 넣고 싶으시면 출처를 함께 주세요.

## 3. 망막박리 (`/retina/detachment`)

**구성**: 질환 소개 → 원인(후유리체박리 → 열공 → 박리) → 증상 4가지 → 응급 안내 띠 → 망막 정밀 검사(Optos 사진) → 수술 2가지(유리체 절제술에 Constellation 사진)

**(a) 기존 원고에서 가져온 내용**
- 정의: 망막이 안구 내벽에서 일부 또는 전부 떨어지는 질환. 수술로 망막을 붙여야 시력 호전을 기대할 수 있는 대표적인 안과 응급질환
- 원인: 후유리체박리에 따른 유리체 견인 → 망막열공 → 액화된 유리체가 망막 아래로 이동. 후유리체박리는 노화로 자연스럽게 생기며 대부분 손상을 주지 않음
- 증상: 비문증, 광시증, 검은 장막이 쳐진 듯 시야 일부가 가려짐, 중심부를 침범하면 급격한 시력 저하
- 치료: 공막돌륭술(실리콘 스펀지·밴드), 유리체 절제술(공기·가스 주입, 엎드린 자세 유지, 가스가 흡수되면 시력 회복)

**(b) 수정·순화한 표현**
| 원문 | 변경 | 이유 |
|---|---|---|
| 오래 방치하면 대부분 실명하게 되며 | 오래 방치하면 실명으로 이어질 수 있어 | 불안감을 주는 단정 표현 순화 |
| 응급수술을 통하여 … 시력을 호전시킬 수 있습니다 | 빠르게 수술로 망막을 다시 붙여야 시력 회복을 기대할 수 있는 | 효과 보장 표현 순화 |
| 3가지 기전으로 발생 | "유리체 견인 → 망막열공 → 망막 아래로 액체 유입" 흐름으로 정리 | 이해하기 쉽게 정리 |
| (기존 플레이스홀더) 수술 전/후 이미지, 레이저 예방 문구 | 삭제 | 원고에 없는 내용 |

**(c) 병원 확인 필요**
- **새로 쓴 문장**
  - 안내 띠: "갑자기 비문증·광시증이 생기거나 시야 일부가 가려 보이면 지체하지 말고 안과 진료를 받으세요." (원고의 증상 내용을 행동 안내로 바꾼 것)
  - 망막 정밀 검사 박스 전체: 열공·박리가 주변부에서 시작되는 경우가 많아 초광각 안저촬영으로 확인한다는 내용
- 망막열공 단계의 **방벽 레이저 치료**는 비문증 페이지에는 있지만 이 페이지 원고에는 없어 넣지 않았습니다. 추가를 원하시면 알려주세요.
- 수술 후 엎드린 자세를 유지하는 기간 등 안내를 더 넣을지 알려주세요.

## 4. 중심성 망막증 (`/retina/csc`)

**구성**: 질환 소개 → 증상 4가지 → 치료 방향 안내 띠(휴식·경과 관찰) → 망막 정밀 검사(Zeiss OCT 사진) → 치료 3가지

**(a) 기존 원고에서 가져온 내용**
- 정의: 황반에 물이 고여 시력이 떨어지는 질환(중심성 장액맥락망막병증). 중년 남성에게서 과로·과음·수면 부족 시 발생
- 증상: 경미한 시력 저하, 중심부에 동그란 원이 보임, 물체가 작게 보임, 변시증
- 치료 방향: 숙면과 스트레스 조절로 3개월 이내에 좋아지는 경우가 많음. 회복이 오래 걸리기도 함. 2~3개월 지나도 호전되지 않으면 치료 시작
- 치료: 국소 레이저(누출점이 중심에서 멀 때, 영구 암점 가능), 광역학 치료(48시간 가시광선 차단, 재발 가능성 감소, 푸른안과에서 시행), 안구 내 항체 주사(1개월 간격 반복 가능, 재발 감소 효과 없음)

**(b) 수정·순화한 표현**
| 원문 | 변경 | 이유 |
|---|---|---|
| 예민한 성격을 가진 중년의 남성이 | 주로 중년 남성에게서 … 스트레스가 겹칠 때 | 특정 성격으로 단정하는 표현 순화 |
| 80-90%의 환자에서는 특별한 치료 없이 3개월 이내에 호전 | 많은 경우 특별한 치료 없이 3개월 이내에 좋아집니다 | 출처 없는 수치 |
| (광역학) 치료 환자의 90%에서 효과가 있으며 | 삭제 | 출처 없는 효과 수치, 효과 보장 |
| (항체주사) 30-60%의 환자에서 효과가 있습니다 | 삭제 | 출처 없는 효과 수치 |
| 비쥬다인이라는 특수약물 | 특수 약물 | 전문의약품 상품명 노출 |
| 맥락막조직의 비정상적인 혈관들의 투과성을 낮추게 됩니다 | 맥락막의 비정상 혈관에서 액체가 새는 것을 줄여 줍니다 | 쉬운 말로 바꿈 |
| 시간 제약이 많은 경우에 시도하기가 어렵습니다 | 일정 조율이 필요합니다 | 어조 정리 |
| 푸른안과에서 가능한 치료법입니다 | 푸른안과에서 시행하고 있습니다 | 어조 정리(사실 확인 필요) |
| 시도해서는 안됩니다 | 시행하지 않습니다 | 어조 정리 |
| (기존 플레이스홀더) 마이크로펄스 레이저 박스 | 삭제 | 원고에 없는 치료법 |

**(c) 병원 확인 필요**
- **새로 쓴 문장**
  - 안내 띠 배지 "먼저 충분한 휴식부터"
  - 망막 정밀 검사 박스 전체: OCT로 액체 양을 확인하고, 필요하면 혈관조영으로 누출점을 찾는다는 내용
  - 광역학 치료의 "햇빛 등" 예시
- **광역학 치료를 현재도 시행 중인지** 꼭 확인 부탁드립니다. 화면에 "푸른안과에서 시행하고 있습니다"라고 적혀 있습니다.
- 메뉴 이름("중심성 망막증")과 본문 제목("중심성 장액맥락망막병증")을 함께 쓰고 있습니다. 하나로 통일할지 알려주세요.
- 효과 수치(80~90%, 90%, 30~60%)를 다시 넣고 싶으시면 출처를 함께 주세요.
