# 원고 검토 요청 — 의료진소개 · 오시는 길 · 메인

기존 홈페이지(의료진소개, 오시는 길, 메인) 자료를 옮기고, 메인 페이지는 진료과목 3개(시력교정 · 백내장 · 망막클리닉 보임) 중심으로 새로 구성했습니다.
의료광고 심의 기준(최초·유일·최고 등 최상급·비교 표현, 치료 효과 보장, 출처·기준 시점 없는 수치)에 걸릴 수 있는 표현은 따로 표시했습니다.

---

## 1. 의료진소개 (`/about/doctors`)

**(a) 기존 원고에서 가져온 내용**
- 소개 문구 "푸른안과 잘되는 이유 — 많은 수술을 하기보다는 수술 후의 관리까지 고려하여 안전한 수술을 합니다"
- 원장 8명의 이름·영문명·진료 분야·한마디·약력(약력/현/전)·요일별 진료시간표·토요일 휴진 주차
- 외래클리닉(유태영·윤상원·강행구·정현진) / 망막클리닉 보임(김한규·차동민·박영명·은준수) 구분, "예약 진료만 가능"(김한규·차동민)

**구성**: 소개 → 탭(전체 / 외래클리닉 / 망막클리닉 보임) → 원장 카드(펼치면 약력 + 진료시간표)

**(b) 수정한 표현**
| 원문 | 변경 | 이유 |
|---|---|---|
| MBC라디오특진 "건강속으로" 출연중 | MBC 라디오 특진 "건강속으로" 출연 | 현재 출연 여부 불확실 |
| Officar / 프랑크프르트 / Municiple / 카톨릭 | Officer / 프랑크푸르트 / Municipal / 가톨릭 | 오타 수정 |

**(c) 병원 확인 필요**
- **진료시간표 전체**: 기존 홈페이지 표를 그대로 옮겼습니다. 요일별 진료/수술, 토요일 휴진 주차(윤상원 1·3·5주, 차동민 4주, 강행구 2주)가 현재와 맞는지 확인 부탁드립니다.
- **엄태웅 원장**: 기존 홈페이지 "망막클리닉 의료진" 탭에만 있고 "전체 의료진"에는 없습니다. 현재 재직 여부를 알려주세요. (지금은 넣지 않았습니다.)
- **진료 분야 표기**: 새 홈페이지에서 다루지 않는 분야(안성형·소아안과·콘택트렌즈·사시)가 원장님 진료 분야에 그대로 표시됩니다. 유지할지, 뺄지 알려주세요.
- **약력 "현" 항목**: 라디오 출연, 주한미군 자문의사, 외래교수, 협회 지부장 등이 현재도 맞는지 확인 부탁드립니다.
- **유태영 원장 한마디 "최고의 진료는 환자와의 약속"**: "최고"가 의료광고 주의 단어입니다. 그대로 쓸지, 바꿀지 알려주세요.
- 원장님 사진은 새로 촬영한 사진으로 넣을 예정입니다.

## 2. 오시는 길 (`/about/location`)

**(a) 기존 원고에서 가져온 내용**
- 교통편 안내: 고속도로(호남·서해안) / 기차(전주역) / 시외버스터미널 / 시내버스 노선, 건물 뒤편 대형 주차장
- 주소, 대표전화, 라식상담 전화, 진료시간

**(b) 수정한 표현**
| 원문 | 변경 | 이유 |
|---|---|---|
| 동산군 IC | 동군산 IC | 오타로 판단 |

**(c) 병원 확인 필요**

- 버스 번호, "전주역 방향 117m 도보"가 최신인지

- 네이버 지도 · 카카오맵 링크 주소

## 3. 메인 (`/`)

**(a) 기존 원고에서 가져온 내용**
- "See more, Do more", "푸른안과는 2001년 개원 이래 오직 '안전함'을 추구해 왔습니다", "많은 수술을 하기보다는 수술 후의 관리까지 고려하여 안전한 수술을 합니다"
- 진료이념 3가지, 시력교정 수술 전 검사 목록(33가지), 장비 사진, 원장 8명
- 하단 띠: "꾸준한 봉사활동, 이것이 푸른안과가 지향하는 바입니다"

**구성**: 메인 비주얼 → 진료과목 3개 소개 → 33가지 수술 전 검사 → 장비 → 진료이념 → 대표 치료 → 의료진 → 영상도우미 → 공지사항 → 진료안내

**(b) 새로 쓴 문구 (원고에 없음)**
- "{2001}년부터 전주에서, 푸른안과는 정확한 진단과 책임 있는 치료로…" (메인 비주얼)
- "소중한 눈을 위해 푸른안과는 세 개의 전문 클리닉으로 진료합니다" 및 각 클리닉 소개 2문단
- 대표 치료 슬라이드 7개의 한 줄 설명
- "의료를 통한 봉사로 지역사회와 아픔을 함께 나누겠습니다" (하단 띠)

**(c) 병원 확인 필요**
- "전문 클리닉", "전문 의료진" 표현 사용 가능 여부
- 연간 방문·수술 수치(10만 명 / 7천 명), 백내장 누적 30,000례, 망막 수술 연 400례는 메인에 넣지 않았습니다. 최신 수치와 기준 연도를 주시면 넣을 수 있습니다.
- 유튜브 채널 주소

## 4. 자주묻는질문 (`/community/faq`) — 새로 작성

기존 홈페이지에 없던 페이지라, 기존 원고와 각 진료 페이지 내용을 바탕으로 질문 12개를 새로 썼습니다 (진료·예약 5 / 시력교정 3 / 백내장 2 / 망막 2). 각 답변에서 관련 페이지로 연결됩니다.

**(c) 병원 확인 필요**
- 답변 전체 (특히 "검사와 수술은 같은 날 진행하지 않습니다", "일부 원장님은 예약 진료만 가능합니다")
- 추가하고 싶은 질문 (비용, 실손보험, 수술 소요시간, 보호자 동반 여부 등)

## 5. 고객후기 (`/community/reviews`)

게시판 형태(목록 + 상세)만 만들고, 형태 확인용 **[샘플] 글 3개**를 넣었습니다. 실제 후기는 관리자 페이지 연동 후 등록되며, 샘플은 오픈 전에 삭제합니다.
목록 상단에 "고객후기는 개인의 경험이며, 치료 결과는 개인에 따라 다를 수 있습니다." 안내를 넣었습니다.

**(c) 병원 확인 필요 — 의료법 주의**
- 의료법 제56조 제2항 제2호는 **환자의 치료경험담 등 치료 효과를 오인하게 할 우려가 있는 광고**를 금지합니다. 병원 홈페이지의 후기도 의료광고로 볼 수 있습니다.
- 운영 방식을 정해 주세요: 누가 올리는지(환자 직접 / 병원 등록), 게시 전 검토 여부, 치료 효과·전후 비교·특정 의료진 추천 표현을 어떻게 걸러낼지.

## 6. 병원둘러보기 · 진료의뢰서 · 온라인 상담

- **병원둘러보기 (`/about/tour`)**: 대표 사진 1장 + 공간별 사진 9칸(외관, 접수·로비, 대기실, 진료실, 검사실, 시력교정센터, 수술실, 망막클리닉 보임, 회복실). 실제 공간 구성에 맞게 목록을 알려주시면 사진과 함께 맞추겠습니다.
- **진료의뢰서 (`/community/referral`)**: 기존에는 망막클리닉 보임 메뉴에 있었으나 커뮤니티로 옮기고 안내 문구를 진료과 공통("푸른안과로 환자를 의뢰하실 때")으로 바꿨습니다. 망막 전용 양식이면 알려주세요. PDF · HWP · DOC 버튼만 만들어 두었습니다(현재 "파일 준비 중"). 기존 홈페이지에 양식 파일이 있지만 주소 표기("전라북도") 등이 옛 정보일 수 있어, 최신 양식 파일을 받아 넣겠습니다.
- **온라인 상담 (`/contact/online`)**: 상담 신청(진료 분야·이름·연락처 입력 창) · 카카오톡 채널 · 전화 상담 안내. 상담 신청은 아직 실제로 접수되지 않으며, 관리자 페이지 연동 시 접수 내역을 확인할 수 있게 됩니다.
